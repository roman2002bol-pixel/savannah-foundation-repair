# Savannah Foundation Repair Co — Local SEO Microsite

Static (HTML/CSS/JS, no build step) local-SEO microsite for **foundation
repair and crawl space work in Savannah, GA**, built on the same
hub-and-spoke model as its sibling site: one hub homepage, a small capped
set of service pages, and a phased, honest set of location pages.

**Brand:** Savannah Foundation Repair Co
**Domain:** `savannahfoundationrepairco.com` (chosen 2026-09-14; the exact
domain was verified unregistered — Roman confirmed and is registering it)

This is the **second site in `Project1/Microsites/`**. Sites here are
local-SEO lead-gen sites that may eventually be rented to, or route leads
to, a real local contractor — which raises a sharper honesty bar on trust
claims than Roman's own detailing sites at `Project1`'s top level.

**Before doing any work on this site, load the `microsite-agent` skill**
(`.claude/skills/microsite-agent/SKILL.md`) — architecture rules, the

Progress and the current build checklist live in `STATUS.md` — read it
before starting a session, update it after finishing one.

## Two things specific to this site

**1. This is a crawl-space market, not a basement market.** Savannah sits
on the coastal Lowcountry plain: the water table is high enough that
digging more than a few feet hits it, so homes here are almost entirely
**raised crawl space** or **slab-on-grade** — basements are rare to
non-existent. Any "basement waterproofing" page or copy would be a
mismatch with the actual local market (that keyword belongs to places like
Baltimore/Towson, not here). Write for crawl spaces, pier-and-beam
settling, sagging floor joists, slab cracking, and coastal moisture.

**2. Do not cross-link with `savannah-tree-removal`.** Same city, same
folder, same owner — but to Google each must look like a completely
independent business. No links between the two sites in either direction,
no shared footer credit, no shared phone number or contact email. The
palette and font pairing here (slate navy + safety orange, Barlow/Inter)
are deliberately unrelated to the tree site's (forest green + amber,
Archivo/Work Sans) for the same reason.
